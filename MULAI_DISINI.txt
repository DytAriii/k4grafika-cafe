   📖 Dokumentasi: SETUP_PDF_EXPORT.md

💾 2. BACKUP DATABASE OTOMATIS
   ✅ Status: SIAP PAKAI
   
   Backup manual:
   > php artisan backup:run
   
   Lihat daftar backup:
   > php artisan backup:list
   
   Lokasi backup:
   storage/app/private/Laravel/
   
   📖 Dokumentasi: CARA_PAKAI_BACKUP.md

----------------------------------------

⏰ JADWAL BACKUP OTOMATIS:
   - 02:00 - Backup full (database + file)
   - 14:00 - Backup full (safety net)
   - 03:00 - Cleanup backup lama
   - 09:00 - Monitor kesehatan

   ⚠️ Untuk jalan otomatis, setup:
   Windows Task Scheduler
   (Lihat: CARA_PAKAI_BACKUP.md)

   File .env sudah dikonfigurasi:
